# [c2] Separation

BR
GUIDETABLE|Keep reusable behavior in|Keep project-specific behavior in||QuestionnaireShell and shared renderers|DSL files and registry entries||`src/lib/questionnaire`|Catalog and database-backed records||`src/lib/activity` and activity provider|Business wording, flow-specific copy, and branded content||`src/lib/auth` and verification helpers|Theme/config variables for a specific offer||Shared route handlers and types|Isolated server helpers for one business process

# [c2] DSL
# [c2] Rules
BR
GUIDETABLE|Rule|Reason||Use short headings|Headings should render in one- or two-word lines so mobile and desktop stay readable.||Use `@syncurl` on useful chapters|Admins and users can link directly to a slide.||Use side-panel chapters|Long flows become easier to browse and bookmark.||Use `GUIDEGRID` and `GUIDETABLE` for reference content|Tables beat walls of text for care guides, docs, and checklists.||Keep action labels simple|Use `Next` and `Back` when the chapter title already appears in the side panel.||Use existing blocks where possible|Avoid rebuilding shops, cart, forms, records, tickets, meals, and account UI inside DSL copy.

# [c2] Affiliate
# [c2] Workflow
BR
GUIDETABLE|Area|What to know||Public flow|`/affiliate` opens the `affiliate-sign-up` DSL application.||Catalog endpoint|`/api/questionnaires/affiliate-sign-up/catalog` supplies eligible stores and product choices.||Email verification|Submitting an application sends the requester a verification link and stores status under `affiliateEmailVerification`.||Review guard|Admins must type `APPROVE`, `DECLINE`, `PAUSE`, or `PENDING` before saving a matching status.||Approval email|New approvals create/update the applicant user record and email a password setup link.||Account handoff|After password setup, the applicant is routed toward login with the account page as the next destination.||Commission source|Shop defaults live in `src/lib/affiliates/storeCommissionSettings.ts`; item overrides live in unified inventory metadata under `affiliateCommission`.||Product preview|`View Affiliated Products` shows matching products, commission percent, estimated JMD amount, product links, and associated links.
